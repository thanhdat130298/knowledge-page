# 01. Thứ tự ưu tiên ôn tập

> Bài 1/22 trong series **Middle Frontend Interview (VTV)**. Ôn theo JD Middle Frontend: JS, TS, React, Next.js, API, testing, performance, a11y, SEO, bảo mật, Cursor.

## Mục tiêu bài học

Sau khi học xong bạn có thể:

- Nắm vững nội dung chính của bài **Thứ tự ưu tiên ôn tập**
- Trả lời được câu hỏi phỏng vấn Middle Frontend liên quan

## Cách học hiệu quả

1. **Tự trả lời trước** — đọc đề, đóng phần giải thích, nói to hoặc viết 2–3 phút.
2. **Đối chiếu** — so với đáp án mẫu, bổ sung ví dụ từ dự án bạn đã làm.
3. **Phiên bản an toàn** — nếu chưa dùng tool (GraphQL, PWA, Docker…), nói rõ *đã tìm hiểu / bài toán tương đương*, không nhận “thành thạo”.

## Kiến thức cốt lõi

## Nhóm ưu tiên cao

1. JavaScript bất đồng bộ, event loop, closure, scope và xử lý lỗi.
2. TypeScript: generic, type narrowing, utility types và định nghĩa kiểu dữ liệu cho component.
3. React: render, state, props, hooks, custom hooks và tối ưu component.
4. Next.js: CSR, SSR, SSG, routing và hydration.
5. Quản lý trạng thái: local state, Context API, Redux Toolkit và Zustand.
6. Tích hợp REST API, loading, error, retry, hủy request và xử lý race condition.
7. Kiểm thử bằng Jest hoặc Vitest, integration test và E2E test.
8. Hiệu năng: lazy loading, code splitting, caching, bundle optimization và Core Web Vitals.
9. Trình bày dự án, ownership, code review và xử lý lỗi production.
10. Sử dụng Cursor: prompt, context, rules, skills và kiểm tra kết quả.

## Nhóm ưu tiên trung bình

1. Responsive design và cross-browser compatibility.
2. Kiến trúc frontend và các design patterns thường dùng.
3. Git Flow, Pull Request, Code Review và CI/CD.
4. Accessibility theo WCAG.
5. SEO cho ứng dụng React và Next.js.
6. Frontend security: XSS, CSRF và CSP.
7. TanStack Query hoặc SWR.
8. Material UI, Ant Design, SASS, SCSS, LESS và PostCSS.

## Nhóm bổ sung

1. Docker.
2. GraphQL.
3. Progressive Web Application.
4. Kỹ năng hướng dẫn thành viên ít kinh nghiệm hơn.
5. Agile, Scrum, Jira và Confluence.

## Tóm tắt nhanh

- Bám stack Middle Frontend: JavaScript, TypeScript, React, Next.js và hệ sinh thái quanh đó.
- Ưu tiên **hiểu cơ chế** và **khi nào dùng**, không chỉ thuộc định nghĩa.
- Luôn có **ví dụ ngắn** và **trade-off** khi trả lời phỏng vấn.

## Tự kiểm tra

1. Tóm tắt 3 ý quan trọng nhất của bài
2. Nêu 1 ví dụ áp dụng vào dự án thực tế
3. Chỉ ra 1 lỗi thường gặp khi trả lời phỏng vấn

## Lỗi thường gặp

- Chỉ học thuộc câu trả lời, không gắn với dự án cụ thể.
- Nhầm các cặp khái niệm gần nhau trong cùng chủ đề.
- Nhận kinh nghiệm sâu với công nghệ chưa dùng thực tế.
- Quên cleanup / dependency / immutability khi nói về React và async.

## Gợi ý luyện thêm

Viết 1 đoạn trả lời phỏng vấn 60–90 giây cho câu khó nhất trong bài, rồi thu âm hoặc nói lại cho mượt.
