# create-public-page

1. Default to Server Component.
2. Export metadata / `generateMetadata`.
3. Provide loading, error, empty states.
4. Responsive layout; no horizontal overflow. Follow `.cursor/rules/layout-overflow.mdc` (article detail + article list cards).
5. Semantic HTML + focusable controls.
6. Draft/private pages must be `noindex`.
