# Article Authoring Guide

## Cách viết bài frontend interview

1. Mở bằng **Câu hỏi phỏng vấn**.
2. Thêm **Câu trả lời ngắn** (elevator answer).
3. Giải thích chi tiết theo heading H2/H3.
4. Có ví dụ code chạy được / dễ đọc.
5. Thêm Junior / Middle / Senior Answer khi phù hợp.
6. Kết bằng follow-up hoặc nguồn tham khảo.

## Short answer

1–3 câu, đúng trọng tâm, tránh lan man.

## Code example

- Chọn đúng language trong code block.
- Ưu tiên ví dụ nhỏ, dễ giải thích trong phỏng vấn.
- Ghi chú output kỳ vọng khi hữu ích.

## Custom blocks

Dùng toolbar Admin Editor: Question, Short, Explain, Note, Warning, Mistake, Follow-up, Junior/Middle/Senior, Experience, Reference.

## Dẫn nguồn

Block Reference: MDN, spec, docs framework — kèm năm nếu nội dung dễ lỗi thời.

## Cập nhật nội dung cũ

Khi sửa bài published: cập nhật excerpt/SEO nếu cần, bump `updated_at`, ghi chú thay đổi lớn trong feedback resolved nếu có.
